# MagiTrickle-MOD

OpenWrt-focused modification layer for MagiTrickle, initially optimized for Netcore N60 Pro.

## Targets
- MagiTrickle 0.8.2-rev2
- OpenWrt 25.12.x
- mediatek/filogic
- aarch64_cortex-a53

## Features
- FULL / BALANCED / MINIMAL provider profiles
- Online CDN-Cloud-MagiTrickle subscription
- Provider validation, cache, fallback and atomic replacement
- ASN/CDN engine
- Mihomo rule-provider integration
- OpenWrt/procd and LuCI integration
- GitHub Actions

The MOD repository contains code and integration. Large, frequently changing rule datasets remain in https://github.com/avgustvishne/CDN-Cloud-MagiTrickle.

Status: initial architecture skeleton; upstream source integration follows next.
